# Tranquilo — умный будильник для Wear OS

Будит в окне перед заданным временем, в момент, когда ты шевелишься: это поверхностный сон,
и просыпаться в нём легче. Работает только на часах, без телефона и интернета.

## Скачать

**[Tranquilo.apk](https://github.com/forsetiqa/Tranquilo/releases/download/latest/Tranquilo.apk)** — последняя сборка, Wear OS 3 и новее.

Новые сборки ставятся поверх старых, настройки сохраняются.
Версия — дата выпуска (ГГММДД), видна внизу главного экрана. Что менялось — в [CHANGELOG](CHANGELOG.md).

## Установка на часы

Нужен компьютер с [Android platform-tools](https://developer.android.com/tools/releases/platform-tools) (утилита `adb`)
в той же Wi-Fi сети, что и часы.

1. На часах: Настройки → Система → О часах → семь раз нажать «Номер сборки».
2. Настройки → Для разработчиков → включить «Отладка по ADB» и «Отладка по Wi-Fi»
   (на Wear OS 4 — «Беспроводная отладка» → «Подключить устройство»: часы покажут адрес и код).
3. На компьютере:
   ```
   adb pair <адрес:порт> <код>      # только на Wear OS 4, один раз
   adb connect <адрес:порт>
   adb install -r Tranquilo.apk
   ```

## После установки

- Разреши уведомления и доступ к пульсу, когда приложение спросит. Для пульса выбери «Разрешить всегда»:
  датчик включается ночью, когда приложение закрыто.
- Настройки → Батарея → отключи оптимизацию для Tranquilo, иначе система может усыпить датчик ночью.

## Как это работает

Задаёшь крайнее время, например 08:30, и длину окна — 30 минут. Получается окно 08:00–08:30.

- **07:00** — включается акселерометр, час измеряет фоновый уровень движений этой ночи.
- **08:00–08:30** — первое заметное движение выше фона (например, переворот) — будильник звонит.
- **08:30** — если такого момента не было, звонит как обычный будильник.

Чувствительность 1–5 задаёт, насколько движение должно превышать фон: 1 — будит только на явном перевороте, 5 — при малейшем шевелении.
Утром блок «Прошлый раз» показывает, как сработало: по движению или в конце окна, фон, порог, пик
и график движений и пульса за ночь — его удобно сравнить с фазами сна в Mobvoi Health.
Пульс пока только записывается и на момент звонка не влияет.

**«Лёг спать».** Нажми перед сном — часы найдут момент засыпания и запомнят, за сколько минут ты уснул.
На той же кнопке: «Прошлый раз: 15 мин», «Лёг 01:16, уснул 01:31» и, после трёх ночей,
«Обычно: 15 мин» — медиана. Всё хранится только на часах. Засыпание — начало первых 10 минут почти без движений.
Если лежать совсем неподвижно без сна, часы посчитают это сном.

**Проверка без ожидания утра:** поставь крайнее время на 10 минут вперёд и окно 15 минут —
мониторинг стартует сразу. Помаши рукой: будильник должен зазвонить.

## Сборка

Kotlin, Jetpack Compose for Wear OS, minSdk 30.
Каждый push в `main` собирает APK в GitHub Actions и выкладывает его в релиз
[`latest`](https://github.com/forsetiqa/Tranquilo/releases/tag/latest).

Подбираемые числа алгоритма собраны в `app/src/main/java/com/tranquilo/alarm/core/MovementAnalyzer.kt`.
